# Recorrido de la demo

[Volver a la presentación](../README.md) · [Abrir Velora](https://velora-chairs.lovable.app/)

## Cómo explorar mi proyecto

Puedes seguir este recorrido sin crear una cuenta ni introducir datos personales.

1. **Explora el catálogo.** Desde el inicio, abre «Productos». La colección presenta diez modelos. Selecciona «Compactas» para ver los dos modelos de esa categoría.
2. **Abre Noma Compact.** Consulta su precio de muestra de 479 €, sus características y su galería. Puedes cambiar de «Vista frontal» a «Vista lateral».
3. **Selecciona una variante.** Marca «Grafito». La etiqueta de color cambia. La galería muestra un acabado de muestra; no debe interpretarse como una reproducción exacta de todas las variantes.
4. **Prueba el carrito.** Añade la silla y abre «Carrito». Con una unidad, el subtotal de ejemplo es 479 € y el total es 482 €, con 3 € de envío ilustrativo. Al aumentar a dos unidades, el subtotal pasa a 958 € y el total a 961 €. Puedes reducir la cantidad o eliminar el producto.
5. **Consulta el contacto y el idioma.** Abre «Contacto» y cambia de ES a EN. El formulario es de demostración y avisa de que no envía datos.

Los importes anteriores corresponden a la revisión del 20 de octubre de 2026. Pueden cambiar si actualizo el catálogo.

## Cómo lo explico en una entrevista

«He creado Velora con Lovable como proyecto personal de portfolio. Es una tienda ficticia de sillas de oficina en la que se puede recorrer un catálogo, consultar fichas, elegir una variante y probar un carrito. Con ella muestro una experiencia web creada con asistencia de IA y explico qué interacciones están disponibles. No procesa pedidos ni pagos reales. En GitHub he organizado las capturas y la documentación para que el proyecto pueda revisarse con facilidad».
