# El proyecto explicado

[Volver a la presentación](../README.md) · [Abrir Velora](https://velora-chairs.lovable.app/)

## Qué presento

Con Velora he creado una muestra de tienda de sillas de oficina con Lovable. El objetivo es que una persona pueda entender la oferta, consultar las opciones de un producto y preparar una selección en un carrito de demostración.

El escenario es ficticio. No lo presento como una implantación comercial ni como experiencia de trabajo para una empresa cliente.

## Cómo se organiza la experiencia

El inicio presenta la marca y lleva al catálogo. El catálogo reúne diez modelos en tres categorías. Cada ficha concentra el precio, la descripción, las características y las opciones de color. El carrito recoge la selección y muestra sus importes de ejemplo.

El sitio también incorpora páginas de información de marca y contacto, además de un selector de idioma español/inglés.

| Necesidad de quien visita la web | Respuesta que presento en la demo |
| --- | --- |
| Entender qué se ofrece | Un inicio centrado en las sillas y un acceso visible al catálogo. |
| Reducir las opciones | Categorías y controles de precio máximo, color y soporte lumbar. |
| Examinar un modelo | Una ficha con galería, características y selector de variante. |
| Revisar una selección | Un carrito con cantidades, eliminación de productos y total ilustrativo. |
| Entender el carácter del proyecto | Avisos visibles de tienda ficticia y ausencia de transacciones reales. |

## La presentación visual

En el resultado utilizo una base clara, imágenes de producto y tonos verdes oscuros. La información se distribuye entre una zona visual y los datos de la silla. La navegación mantiene los accesos al catálogo, la marca, el contacto y el carrito.

Estas decisiones pueden observarse en las [capturas del repositorio](../assets/) y en la demo. No afirmo que hayan mejorado ventas o conversión: no dispongo de mediciones comerciales ni de un estudio con usuarios.

## Qué puedo explicar a una empresa

Puedo mostrar el recorrido completo de una demo de tienda, explicar cómo he utilizado Lovable y diferenciar sus interacciones disponibles de los elementos simulados. El proyecto permite conversar sobre organización de contenidos, experiencia de catálogo y uso de IA para crear una aplicación web.

Aquí documento el resultado publicado y el uso de Lovable. El código de la aplicación no está incluido en este repositorio; las funciones comprobadas se detallan en el [registro de revisión](verificacion.md).

## Qué ampliaría antes de un uso comercial

Si este concepto se llevara a una tienda real, propondría definir primero los requisitos de negocio y validar el recorrido con usuarios. Después habría que implementar y revisar el tratamiento de datos, el inventario, los pedidos, los pagos y los envíos.

También propondría una revisión de accesibilidad, dispositivos móviles y rendimiento. Son siguientes pasos posibles; no los presento como trabajos ya realizados.
